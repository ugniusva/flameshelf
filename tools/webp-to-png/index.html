WebP to PNG

Convert a WebP image to PNG and preserve its transparency.

Drop images here

JPG, PNG, HEIC, SVG, RAW and more · up to 120 MB total

You can drop files anywhere on this page.

    Exports use the first frame or page. Layers, vectors, and camera RAW data become ordinary pixels.

    Example

    Drop a WebP image and select Convert to PNG. The downloaded file retains its alpha channel.

    Supported input formats

    JPG, PNG, WebP, AVIF, HEIC / HEIF, SVG, GIF, BMP, TIFF, ICO, CUR, JPEG XL, JPEG 2000, J2K, QOI, TGA, DDS, PSD, OpenEXR, Radiance HDR, PBM, PGM, PPM, PAM, PCX, Sun Raster, SGI, XBM, XPM, WBMP, MIFF, FITS, DCX, OTB, Aseprite, DICOM, DNG, Sony ARW, Sony SRF, Sony SR2, Canon CR2, Canon CR3, Canon CRW, Nikon NEF / NRW, Olympus ORF, Fujifilm RAF, Panasonic RW2, Hasselblad 3FR, Kodak DCR, Kodak KDC, Epson ERF, Phase One IIQ, Mamiya MEF, Leaf MOS, Minolta MRW, Pentax PEF, Leica RWL, Samsung SRW.

    Keep transparent edges when exporting to PNG

    Drop the WebP image and use the preselected PNG output. This is useful for stickers, logos, or screenshots when your editor expects a PNG.

    PNG keeps transparency, though the exported file can be larger. If the original is an animated WebP, the result is a still image. Save the original to keep the animation.
