The tool shelf

FlameShelf is a free collection of file converters, PDF tools, and calculators that run in your browser. Your files stay on your device.

    Find the right tool for your file

    Drop a file anywhere on the page. The workbench checks the file and offers actions for its format. A photo can go to a converter, compressor, or resizer. A PDF can go to a page tool or a text converter.

    If you already know the format you need, search the tool index for a pair such as HEIC to JPG or CSV to JSON. Processing takes place on your device, and you download the result from the tool page.
